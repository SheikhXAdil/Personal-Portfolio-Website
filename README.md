# Personal Portfolio Website

My personal portfolio website built to showcase my background, skills, projects, experience, and other work as a software engineering student and developer.

The website was built using **Next.js 13** and **Tailwind CSS**.

## Live Website

**[Muhammad Adil Nadeem — Portfolio](https://muhammadadilnadeem.vercel.app/)**

## About

This project is a personal portfolio website created to provide a central place for presenting my professional and academic profile.

It includes information about my:

* Background and introduction
* Technical skills
* Projects
* Experience
* Education
* Other relevant work and activities

The portfolio has evolved alongside my development experience and serves as both a personal website and a practical project for working with modern web technologies.

## Tech Stack

* **Next.js 13**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **PostCSS**
* **ESLint**

## Purpose

This repository contains the source code for my personal portfolio website.

It is also part of my collection of personal projects maintained on GitHub and reflects my experience with **React, Next.js, TypeScript, and modern frontend development**.

## Related Work

Some of the projects and work presented on the portfolio have their own dedicated repositories on my GitHub profile. Those repositories contain the individual project source code and documentation, while this repository contains the portfolio website used to present them.
